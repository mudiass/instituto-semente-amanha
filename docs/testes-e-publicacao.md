# Testes e publicação

## Instalação e validação
```bash
npm install
npm run dev
npm run lint
npm run build
npm start
```

## Checklist
- [ ] Links do menu levam às seções certas.
- [ ] Banner aparece como fundo e o texto permanece legível.
- [ ] Imagens têm textos alternativos quando informativas.
- [ ] Testar larguras de 320, 375, 768, 1024 e 1440 px.
- [ ] Conferir navegação por teclado, foco e contraste.
- [ ] Verificar erros no console e build de produção.
- [ ] Confirmar o conteúdo com os responsáveis pelo instituto.
- [ ] Adicionar somente canais oficiais de contato.
- [ ] Revisar autorização de imagens e marcas antes da publicação.
